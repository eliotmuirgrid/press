# Iterate

This is a value we live every day.

During our restructuring, we iterated extremely rapidly—constantly trying new forms of messaging and observing what worked. We take the same approach in development.

When dealing with complex systems like businesses, **iteration is essential**.

You cannot reliably predict how changes will impact a system. A change needs to be applied, and then the system carefully observed.

- Did it improve?
- Did something get worse?

Iteration enables us to learn quickly, adapt, and continuously improve.

If we screw up then we reverse and pretend we never did that!
