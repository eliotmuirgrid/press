# Lean

**When you choose to operate with lean resources it forces you to think clearly**.

Operating with lean resources forces you to think much more clearly as to what matters.

There are three examples I can think of where having leaner resources actually
resulted in better decisions being made.

 - Not having the time to resurrect the Chameleon only license generator.
 - Not choosing to analyse a crash dump due to Oracle drivers.
 - Not choosing to help a client figure out how to make Windows file sharing permissions work with Iguana.
 - Not choosing to create a very elaborate licensing system which had a lot of technical debt and turned counting licenses into an elaborate dance.

Under the old structure someone would have dutifully tried to solve each one of these
problems.  But better choices were made because the resources did not exist to solve these problems.

It's not intutitive to most people but operating with less resources is actually very sensible.
