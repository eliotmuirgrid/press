# Flow

Making development extremely easy, while delivering high-performance, system-level programming to a broad audience, is a key idea behind what will make [Flow](/flow) one of the most disruptive technologies of our time.

Currently, creating software is a lot of work, and AI—such as that produced by Anthropic—hasn’t improved the situation.

Why is that?

It’s entropy.

Yes, Anthropic with Claude code teases us with what’s possible, but they don’t produce maintainable, secure code. The code they generate is riddled with vulnerabilities. How are the humans who depend on that code supposed to secure it and maintain it? It’s like drinking from a firehose.

Overwhelming.
