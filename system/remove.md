# Remove

**The most important first step in system improvement is to remove unnecessary elements.**

It’s remarkable how universally true it is that the easiest way to reduce entropy in a system is to remove unnecessary elements.

This is a fundamental concept I return to constantly. I’ve been spending some time at a beach house, and it’s been a perfect setting for reflecting on this principle. Decluttering is a practical way to see it in action: for example, in the kitchen, removing items from drawers that only add confusion or block the tools I actually need. If I discover I actually need something, I’ll fetch it from storage. For now, the result is bliss: drawers that open easily and contain only what I really use. Brackets, screws, and oversized tools that jam up the works? Not so great for stirring soup.

> The same principle applies to building stable code and organizations: less is more. Just because something is convenient doesn't mean it's a good idea. Step back, think long term, and remove unnecessary complexity. Whether in software, business, or life, the hardest clutter to remove is often the bad decisions we never needed to make.
