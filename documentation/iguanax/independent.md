# Independent

The design of Iguana X needs to shift to a model where it does **not** require access to external platforms like Bitbucket and GitHub in order to load libraries.

A major reason many Iguana 6 users remain on this platform is its robustness, which comes from not needing any external resources.

We want to move in the same direction with Iguana X.

Both Iguana X and Iguana 6 could benefit from having a simpler integration with GIT, giving more global visibility of the code inside an engine.
