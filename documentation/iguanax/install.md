# Installation

I believe that, for both products, the direction needs to shift away from encouraging in-place installs. Instead, installation should follow the same approach for both Iguana X and Iguana.

This [Iguana 6 section](https://interfaceware.com/documentation/iguana/iguana621/installer) explains the approach and reasoning.

Critical infrastructure software requires slow, meticulous upgrades, and it must be possible to run the old and new versions in parallel.

Our customers need stability, and that is our goal. In-place upgrades for Iguana X did not acknowledge this reality, so we need to be realistic about what really matters.
