# Where is the Iguana X Configuration?

If you go to any of your Iguana X translator windows you can see the path
to where the translators have their data:

For instance on my Mac:

```
/Users/eliotmuir/Library/IguanaX/config/
```

Under this directory you will find all the code for your Iguana X configuration.
The directories are:

 - comps - components
 - other - keys for the webserver, the IguanaLicense file
 - reports - crash reports
 - settings - settings
 - users - user information

Enjoy.
