# Chameleon

A huge upgrade for Iguana 6 users would be to back port the simpler
HL7 grammar system from Iguana X.

See [Simple HL7 Grammar](/documentation/chameleon/future).

This would make it vastly easier for organizations to consider slowly migrating to Iguana X.

It would also mean that Iguana 6 can be used without needing the Chameleon GUI which only
works on windows.  This would be really convenient for cloud users.
