# Standardization

For many health IT companies they may just have an initial hurdle of working
out what versions of their interfacing platform they have in production. Getting
a handle on that so there is an agent that can report this information for central
collection is a key initial milestone to access the variability of the installations
and what the overall shape of installations is in.

Are they grouped around particular versions of Chameleon or is a very heterogenous
environment with many versions in play.

This makes it very important when making alterations to these environments to avoid
changing global settings like PATH and registry values.

When installing new software into such critical production environments it's very important
to do it very conservatively - using approaches that unzip into directories and do not make
any uncontrolled global changes on the machine.

That of course needs to controlled by trusted parties to even place that software using
private/public key technology to control when and who does it.  Security has to be considered
at every stage.
