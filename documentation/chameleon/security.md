# Chameleon comes with Iguana

Chameleon was the first product and we used to offer it seperately.

During the 2026 restructuring it became obvious that all our Chameleon
customers were running HL7 over non encrypted sockets which didn't make
any sense.

So now we ship Chameleon together with Iguana so now all our Chameleon
customers have the opportunity to do what we've been saying for years.

Use Iguana instead.  It's better.  It has modern must have features like
the ability to encrpyt your streams of TCP/IP data so that a kid with
a packet sniffer cannot harvest all that juicy confidential data.

You know you are supposed to be encrypting that stuff right?  Most countries
have laws which are frequently ignored by health care providers and heathcare
IT vendors that say you should do this.

Now you have a simple way to be compliant with a tiny bit of work!  No
excuses now!  Okay maybe you have some crazy personal issues but when you
have some downtime - get it done then.  We all have periods in our life
when there isn't some crazyness stopping us from getting things done.
