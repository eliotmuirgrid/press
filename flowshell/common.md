# Common Tracing

This is really cool. So in Iguana customers didn't get access to the source code of anything.  In this model you
do.  It means if you hit a bottleneck, the no problem - you can optimize the crap out of it.

Flow combines the two languages together using similar conventions - the code is laid out in adjacent directories
and in fact you probably could even have some C++ code and Lua code in the same directory mixed together.

I am using the concepts of prefixes to unify the way that tracing works.

It will be beautiful in that it should start to become apparent how the ultra secure model will work.  As
customer not only can you read the code, but you will be able to trace exactly how it works.

My desire is to help my customers and users grow and become more capable rather than less.

AI should be used to help develop and grow people. Not replace them.
