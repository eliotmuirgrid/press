# Flow Lua as the New Iguana Runtime

Imagine if every interface was just code—clean, simple, and self-contained. With **Flow Lua** as the runtime, each interface could be bundled up as a tiny, standalone binary. This binary is completely open source, containing only the code necessary for its specific function.

For the commercial side, we would offer an advanced GUI for logging, dashboards, and management features. But the core interfaces—the parts that actually move and transform data—are lightweight, isolated programs. 

This makes them incredibly easy to debug, trace, and maintain. It’s a resilient, radically simplified approach to interface engines—one where the complexity is stripped away, and each interface runs as its own robust mini-application.

It’s a major redesign for how interface engines work, offering transparency, traceability, and flexibility.

Much much better for security too.
