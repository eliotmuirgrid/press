# Optimization

**Windows is notorious for getting slower as an operating system over time.**

Windows has gained a reputation for gradually slowing down over time. 

The reality is, Microsoft doesn’t seem particularly motivated to fully address this issue. After all, there’s far more profit to be made from customers purchasing new computers rather than refining and optimizing the existing operating system. 

Over the years, many of the original developers of Windows have long since retired, likely enjoying the wealth they accumulated from Microsoft stock options. For the current teams, delving into and trying to resolve decades of accumulated “legacy debt” within Windows would be a monumental task—one that’s probably impossible to fully accomplish without jeopardizing the backward compatibility that has always been a top priority for Microsoft. As a result, meaningful optimization often takes a back seat, leaving users to wrestle with the realities of an aging, complex system
