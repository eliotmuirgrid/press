# Bottlenecks

**What are the top performance bottlenecks in Windows likely to be?**

We need to think about the fundamental resources in any computer
and ask the question which is the main bottleneck.

 - [Disc usage](drive.md) - long term memory that persists for a long time
 - [Memory usage](memory.md) - short term memory for current tasks.
 - [CPU usage](cpu.md) - central processing unit - the brain.
