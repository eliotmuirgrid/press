# Morse Code

**Morse Code** is a way to represent letters and numbers using short and long signals called "dots" and "dashes." For example, the letter A is “.-” and the letter B is “-...”.

## Was Morse Code the First Way to Transmit Data?

Morse Code was the first major **electronic** method to send information over long distances using telegraphs. Before Morse Code, people used things like smoke signals, drum beats, or carrier pigeons to send simple messages—but Morse Code was the first system to send detailed messages quickly and reliably through wires.
