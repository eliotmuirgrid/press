# HDMI

**Managing Cables with the Raspberry Pi**

One of the biggest headaches we’ve run into with the Raspberry Pi is dealing with the cables, especially with how tiny the board is. It doesn’t take much for the whole thing to slide around, particularly when I’m using adapters like micro HDMI to full-size HDMI. Even the slightest bump can make the HDMI connection drop and suddenly there’s no display—frustrating doesn’t even begin to cover it.

We tried switching to a longer cable that does the HDMI conversion directly, thinking it might help keep things steady. For reference, this is the specific cable we went with:

[Micro HDMI to HDMI Cable on Amazon](https://www.amazon.com/dp/B0CQSZCH7D?ref=ppx_yo2ov_dt_b_fed_asin_title&th=1)

Unfortunately, it still didn’t really solve the issue. The cable simply didn't work at all.

In the end, it feels like the real fix will have to be something more custom—maybe 3D printing a mount or bracket to firmly hold the adapters in place. That’s probably the way to go if you’re looking for a cleaner, more dependable Raspberry Pi setup. Definitely a project I’m considering for the future
