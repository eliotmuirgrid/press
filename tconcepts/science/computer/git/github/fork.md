# Forking a Repository on GitHub

Here’s how you [fork](../fork) a repository on GitHub. They provide a graphical user interface (GUI) for this process. It’s okay—not great.

You will need to:

 - Create a GitHub account.
 - Fork the repository.
 - Edit using the in-place editing tools.
 - Submit a pull request.

Let me know if you need more detailed instructions for any of these steps.
