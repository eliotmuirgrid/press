# Forking a Repository on GitHub

Here’s how you [fork](../fork) a repository on GitHub. GitHub provides a graphical user interface (GUI) for this process. It’s okay—not great.

You will need to:

- Create a GitHub account.
- Fork the repository.
- Edit using the in-place editing tools.
- Submit a pull request.

Let me know if you need more detailed instructions for any of these steps. Eliot will probably ask you for screenshots, and will gratefully accept any help documenting someone else’s product.

Generally, this is what makes open source unstoppable: lots of people working together, which makes it difficult for corporations and governments to control it. A lot of good fun!
