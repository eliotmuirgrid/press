# GitHub

**GitHub** is a web-based platform designed for version control and collaborative software development. It allows individuals and teams to store, manage, and track changes in their code using **Git**, a popular version control system. GitHub makes it easy for developers to work together on projects, contribute code, review changes, and manage issues.

## Commercial Ownership

GitHub is a **commercial website** owned by **Microsoft**. Microsoft acquired GitHub in 2018. While the platform has value, this value is compromised by the commercial interests of its corporate owner.

The user interface is often more complicated because Microsoft tries
to cross-sell services to its users. Until better alternatives exist, though,
we are all stuck with using it.
